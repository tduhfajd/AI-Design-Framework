# Участие в проекте

Спасибо за интерес к AI Design Framework. Полезны конкретные сценарии,
воспроизводимые ошибки, улучшения шаблонов и дополнительные среды проверки.

## Локальная работа

Python 3.10+, без сторонних зависимостей:

```sh
python3 scripts/validate.py
python3 -m unittest discover -s tests/unit -v
```

Проверки те же, что в CI. Они не запускают агента и не доказывают визуальное качество.
При изменении skill-файлов обновите соответствующие SHA256 в package-manifest.json
после осознанной проверки diff. Сохраните происхождение и лицензии адаптаций.

## Изменение поведения

Опишите проблему через запрос пользователя, исходные материалы и разрешённые действия.
Покажите, какое поведение ожидается, что произошло и как вы проверили изменение.
Пользуйтесь [каталогом сценариев](docs/framework/VALIDATION.md).

Если нужны новые поведенческие прогоны, отделяйте исполнителя от подготовки
ожидаемого ответа; сохраняйте версии, входы, ограничения и неудачные повторы.
Визуальное замечание подкрепляйте просмотренным рендером в нужном масштабе.
Скилы не должны требовать шрифт, палитру, радиус или обязательную секцию для всех сайтов.

## Pull request

- Объясните конкретную проблему и новое поведение.
- Сохраняйте самодостаточность пакета и существующие проектные решения.
- Обновите документацию и CHANGELOG по изменённому объёму.
- Укажите команды проверок и непроверенное. Для UI приложите разрешённые снимки.
- Исключите личные данные, пароли, базы, пользовательские профили и частные пути.

[Шаблоны GitHub Issues](https://github.com/tduhfajd/AI-Design-Framework/issues/new/choose)
помогают оформить воспроизведение и предложение. Не загружайте конфиденциальные
материалы клиентов. Сообщения о чувствительных проблемах — по [SECURITY.md](SECURITY.md).
