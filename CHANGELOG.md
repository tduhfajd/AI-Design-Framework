# Changelog

## 0.4.0 — 2026-10-19

### Добавлено

- Седьмой пакет ai-design-elements: подбор, адаптация и ревью элементов внутри
  существующих этапов; приоритет компонентов проекта и действующего дизайна.
- Каталог 43 источников без стороннего исходного кода. CLI на Python 3.10+ без
  зависимостей: русский/английский поиск, фильтры, локальные записи, черновик
  и проверка реестра с актуальной версией.
- В direction/implementation/review и три шаблона включена условная маршрутизация
  и фиксация происхождения, прав, notices, зависимостей и доказательств.
- Установщик поддерживает новый пакет отдельно и в полном наборе. Генерируемый
  Python bytecode исключается из копирования, сравнения и контрольных сумм;
  изменённые исходники по-прежнему вызывают отказ до копирования.

### Исправлено и проверено

- English dialog-поиск не находил Svelte-кандидата: добавлены двуязычные метки,
  без изменения статусов проверки источников. Новая регрессия и свежий агент
  подтвердили исправление.
- Восемь независимых сценариев v1 и один повтор на v2 (9 контекстов).
  [Обзор и ограничения](docs/VALIDATION-RESULTS.md#elements-0-4-0).
- 23 переносимых автоматических теста элементов и проверки установки включены
  в CI. Они не запускают агентов/браузер и не заменяют визуальную приёмку.

### Совместимость и обновление

- Четыре этапа и 22 основных критерия сохраняются; спецификация контрактов 0.2.
  Дистрибутив: 7 пакетов / 36 файлов; VERSION согласован с package-manifest.json.
- Для добавления только нового пакета используйте --skills ai-design-elements.
  Изменившиеся основные пакеты обновляйте после сравнения/сохранения своих правок;
  автоматической перезаписи нет. [Подключение и обновление](docs/GETTING-STARTED.md).
- Каталог не одобряет код. verified-record проверяет декларации, не истинность
  доказательств. MCP, платные API, сторонние компоненты и глобальные настройки
  не устанавливаются. Аппаратные устройства и полная WCAG-проверка не подтверждены.

## 0.3.0 — 2026-10-19

### Изменено

- В существующие четыре этапа встроен сквозной стандарт качества: содержание
  verified/placeholder/missing, обоснование структуры и источники доказательств.
- Обновлены четыре основных навыка, пять шаблонов и два руководства проверки.
  Замечания разделяют категорию, основание A/B/C, уверенность и P0/P1/P2.
- Матрица готовности учитывает путь, адаптивность, доступность, lab/field скорость,
  наблюдаемую безопасность, SEO и визуальную уместность в проверенном объёме.
- Уточнены границы: axe не доказывает полную WCAG-конформность, Lighthouse не
  заменяет field CWV, отсутствие AI-файлов не означает дефект, согласованный бренд
  и локальная правка не требуют новых концепций.

### Проверено

- Q-01–Q-08: восемь сценариев, девять независимых рабочих контекстов, обе ветви Q-07.
  Поведение соответствует ожиданиям; ошибки CLI-размещения первых пяти прогонов
  сохранены и отделены от оценки навыков. Обвязка исправлена и проверена отдельно.
- T-22: четыре контекста direction/implementation/review до и после правки;
  Unicode, HTML entity, SVG, CSS hover/focus на 1440/390 px. Ожидания выполнены;
  навыки после испытаний не менялись.
- Дополнительно методология применена к реальному одностраничному сайту:
  полный аудит выявил проблемы позиционирования/доказательств и mobile lab LCP.
  Это собственный аудит, не независимый тест навыка или подтверждение полевых метрик.

### Совместимость и ограничения

- Четыре этапа, 22 основных критерия, имена шести пакетов и команды установки
  сохраняются; спецификация контрактов остаётся 0.2. Версия дистрибутива — 0.3.0.
- При обновлении установщик по-прежнему останавливается на отличающихся пакетах:
  сначала сохраните и осознанно сравните локальные изменения по инструкции обновления.
- Experimental: аппаратные телефоны, устойчивость на множестве моделей/повторов,
  все CMS и полный набор сценариев не подтверждены. Старые CMS-ограничения сохраняются.
- Исследование источников готовых UI-компонентов остаётся входным материалом,
  а не реализованным каталогом, MCP-интеграцией или разрешением установки библиотек.

## 0.2.0 — 2026-10-15

Подготовлена публичная редакция; GitHub Release или тег этим файлом не создаётся.

### Добавлено

- Четыре самодостаточных скила: discovery, direction, implementation, review.
- Две локальные адаптации: break-ui и mobile-native с MIT notices и происхождением.
- Контракты, семь маршрутов, каталог сценариев, шаблоны и UI-метаданные.
- README, установка в конкретный проект, примеры запросов и правила участия.
- Установщик без перезаписи, офлайн-проверка состава/ссылок/сумм и unit tests.
- GitHub Actions для этих локальных проверок; GitHub Issue/PR templates.
- Обезличенный обзор испытаний и выбранные синтетические снимки.

### Известные ограничения

- Экспериментальная методология; стабильное качество без контроля человека не доказано.
- В review пропущена тень подписи; один CMS-перенос требует HTML для главной.
- Поведенческий runner, CMS, исходные базы и приватные журналы не включены.
- Физические телефоны, большие JPEG, другие CMS и оплата не проверены.
