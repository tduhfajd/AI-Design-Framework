# Поиск элементов

Каталог `resources/catalog.json` содержит 43 указателя: базовые элементы,
headless-примитивы, композиции, движение, формы/данные, иконки, типографику и инструменты.
Он не является shadcn registry, зеркалом исходников или списком одобренных компонентов.
Цена, стек, количество элементов и лицензия из исследования требуют актуализации
для выбранного кандидата. Только `source_checks` обозначает нашу проверку
конкретного сведения по первоисточнику; это не аудит компонента.

CLI использует Python 3.10+ без сторонних зависимостей, сети и исполнения команд.
Ниже `SKILL` — путь к установленному пакету `ai-design-elements`.
Запускай по абсолютному пути, чтобы рабочая директория оставалась проектом сайта:

```bash
python3 "$SKILL/scripts/elements.py" search "форма" --stack react --limit 5
python3 "$SKILL/scripts/elements.py" search "dialog" --category headless
python3 "$SKILL/scripts/elements.py" search "кнопка" --stack html --access free
python3 "$SKILL/scripts/elements.py" search --id react-bits
python3 "$SKILL/scripts/elements.py" search "форма" --records design/ELEMENTS.json
```

Результат — JSON. Локальные записи идут отдельно и раньше внешних ресурсов;
поиск не делает их автоматически пригодными для другого проекта/версии.
Слова запроса ищутся без учёта регистра, все слова должны присутствовать;
русские и английские термины добавлены по назначению. Эти поисковые метки
обозначают область поиска, а не проверенный список компонентов источника.
Это текстовый фильтр, не семантический
поиск. `--stack` фильтрует исследовательскую подсказку стека, не доказывает
совместимость. Фильтры category/access относятся к внешним ресурсам; явный
`--records` добавляет локальные совпадения независимо от этих фильтров.
`--limit` ограничивает каждый список; `matched` показывает полное число совпадений.
При нуле совпадений расширь запрос или обратись к официальной документации.
CLI не сканирует код проекта: существующие компоненты нужно найти и прочитать.

Если MCP уже доступен и полезен задаче, используй его для актуального поиска
и просмотра исходника. Результат MCP остаётся внешним кандидатом, включая
реестры с prompts/hooks/config. Проверь состав и действия item, URL, зависимости
и команды перед переносом. Без MCP используй прямые официальные ссылки;
его отсутствие не блокирует работу.

Подключение нового сервера — отдельная настройка по запросу; пакет не меняет
глобальную конфигурацию. Актуальные способы подключения ищи в
[документации shadcn MCP](https://ui.shadcn.com/docs/mcp).
Примеры с `latest` из исследования не являются зафиксированной версией зависимости.
