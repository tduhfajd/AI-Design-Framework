# Каталог реалистичных крайних данных

Выбирай строки по карте полей и пределам продукта. Это тестовые примеры,
а не значения, которые нужно подставлять в настоящий аккаунт или каталог.
Адреса и URL используй только на example.com, example.org или .test.

| Тип | Применимые пробы | Что наблюдать |
| --- | --- | --- |
| Имя/название | Длинное составное имя, `Jo`, `王秀英`, `👩🏽‍💻 Priya`, диакритика, пустое/пробельное значение при допустимости | Переносы, инициалы, fallback, высота строки |
| Идентификатор | `bartholomew.fitzgerald@northwind-industries-holdings.example.com`, длинный путь/имя файла, похожие строки с разным окончанием | Переполнение, доступность полного значения и различимость |
| Подпись | Длинный статус, длинная локализованная кнопка, разрешённый перенос строки | Кнопка остаётся доступна; соседние элементы не вытеснены |
| Текст | Реалистичный верхний предел схемы; буквальные `<b>текст</b>` и амперсанд без исполнения | Экранирование, перенос, полнота информации |
| Число | 0, 1, 2, большое допустимое значение; отрицательное/null только если допускается | Разряды, локаль, склонение, точность, отсутствие `NaN` |
| Коллекция | Пусто, одна строка, смешанные данные, граница страницы и на один больше | Пустой результат, счётчик, пагинация, сохранность действий |
| Медиа | Нет изображения, локальная 404, очень широкая/высокая пропорция | Fallback, кадрирование, изменение компоновки |
| Состояние | Ошибка, ожидание, частичные данные, доступные enum-варианты | Честный текст, отсутствие скрытого/неработающего действия |
| Дата | Реальные крайние даты предметной области, смена часового пояса | Корректность формата; неизвестная дата не выдана за 1970 год |

Большую коллекцию проверяй только в объёме, допустимом источником и интерфейсом.
Не создавай выдуманный API или состояние оплаты для статической карточки.
RTL/dark и специальные локали проверяй при поддержке продуктом; международное
имя само по себе не требует добавлять новый язык сайта.

## Частые причины, которые нужно подтвердить

- Flex/grid оставляет тексту min-content ширину и вытесняет конечное действие.
  Проверь фактическое положение кнопки и доступность, затем оцени `min-width: 0`
  или `minmax(0, 1fr)` на нужной колонке.
- Неразрывная строка выходит за контейнер. Перенос/обрезку выбирай по значению
  поля: сравниваемые суммы и числа не должны терять разряды.
- Аватар или иконка сжимается. Проверь размеры; возможное решение — ограничение
  shrink для элемента фиксированного размера, не для всего содержимого.
- Обрезание маскирует дефект. Для имени/заголовка часто нужен перенос;
  для вторичных метаданных возможна обрезка с доступным полным значением.
  Одинаково обрезанные идентификаторы могут потерять различимость.
- Обычная строка работает, а пустая/одиночная показывает `undefined`,
  неверное склонение или недоступное действие. Проверяй и данные, и их смысл.

Наличие CSS-рецепта не доказывает исправление. После изменения проверь обычный
набор, применимые крайние состояния и сценарий действия на новой версии.
