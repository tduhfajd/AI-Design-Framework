# Аудит без исправления продукта

```text
Примени $ai-design-review к разрешённому локальному адресу сайта.
Сопоставь с действующим design/DESIGN.md, проверь основной пользовательский путь,
мобильный и настольный размеры. Исходники и данные CMS не меняй.

Отчёт и снимки разрешено сохранять в отдельном каталоге qa-report/.
Если редакторский save/reload требует изменения записи, отметь эту часть
непроверенной: тестовая запись в этой задаче не разрешена.

Для каждого дефекта укажи версию, воспроизведение, доказательство, последствие
и предложенное исправление. Вкусовые предложения отдели от нарушений требований.
Список созданных снимков и список фактически просмотренных экранов веди отдельно.
```

Для крайнего текста можно добавить break-ui, разрешив отдельную фикстуру вне продукта.
Исправления начинаются отдельной задачей implementation с конкретным объёмом.
