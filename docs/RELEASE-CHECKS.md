## Behavior Now Reflected

README описывает оценку дизайна по задаче, содержанию, иерархии, адаптивности
и пользовательскому пути. Подробности технических испытаний остаются в их обзоре.

Схема процесса теперь подключена как обычное изображение с текстовым описанием;
она не требует Mermaid renderer. Содержание этапов и цикл исправлений сохранены.
После этой правки локальная проверка и все девять тестов повторно прошли.

Шесть пакетов и 28 файлов скилов совпадают побайтно с исходной рабочей редакцией.
Пути и суммы — [manifest](../package-manifest.json). Новое поведение в публичном
пакете — установщик без перезаписи и проверка состава; сами скилы не улучшались.

Локально выполнены на Python3.14.6:

```sh
python3 scripts/validate.py
python3 -m unittest discover -s tests/unit -v
```

Состав, ссылки и суммы прошли проверку; девять тестов прошли.
Отдельно выполнены CLI dry-run → установка → повтор в каталоге с пробелами;
существующий AGENTS.md сохранён. YAML-файлы проверены парсером Ruby Psych.
Настоящее выполнение workflow на GitHub ещё не проверено; matrix3.10/3.13
описывает будущие CI-запуски, а не локально пройденные версии Python.

Баннер просмотрен в bundled Chromium на настольной и мобильной ширине.
