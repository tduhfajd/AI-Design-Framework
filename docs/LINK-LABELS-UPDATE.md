## Behavior Now Reflected

Ссылки и кнопки получают ясную текстовую подпись без декоративных стрелок,
включая SVG, иконки и CSS при hover/focus. Правило задано владельцем фреймворка.
Каждый скил применяет его самостоятельно. Состав шести пакетов сохранён.
Валидатор пакетов прошёл; девять тестов установщика прошли. Четыре изменённых
скила отдельно прошли quick_validate; исходная и публичная копии совпадают.

## Open Documentation Questions

T-22 подготовлен, независимый поведенческий прогон новой редакции не выполнен.
Исторические испытания и обзоры 0.2.0 не подтверждают новое поведение.

требуется просмотр обычного, hover- и focus-состояния.
