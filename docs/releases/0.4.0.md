# AI Design Framework 0.4.0

19 октября 2026. Семь пакетов, 36 исходных skill-файлов.

## Изменения

Добавлен ai-design-elements: поиск/выбор существующих и внешних элементов,
адаптация к DESIGN, происхождение и проверка в интерфейсе. Каталог 43 указателей,
Python CLI без зависимостей, локальные решения и актуальность доказательств.
Внешний код не включён и не устанавливается. Метки `verified-record` и `free`
не подтверждают права или качество компонента.

Изменены условные подключения direction/implementation/review и три шаблона.
Четыре этапа и спецификация контрактов 0.2 сохраняются. Установщик поддерживает
новый пакет отдельно/в полном наборе, отказывается от перезаписи отличающихся
исходников, исключает служебный Python bytecode. VERSION и manifest согласованы.

## Ship Status

Ready to ship по локальным проверкам. Фактическая публикация и CI отражаются
в GitHub Release/Actions для соответствующего коммита.

## Base Branch

main; предыдущая версия 0.3.0, базовый публичный коммит 8075254.

## Branch State

Изолированный переносимый пакет. Все skill-файлы совпадают побайтно с рабочей
редакцией; ai-design-elements совпадает с испытанным v2. Суммы — package-manifest.json.

## Checks Run

- `python3 scripts/validate.py`: семь пакетов, 36 файлов, ссылки/суммы/формат.
- `python3 -m unittest discover -s tests/unit -v`: 34 теста — 23 для элементов,
  11 для установщика/валидации, включая отдельную установку и работу CLI из пути
  с пробелами, служебный cache, сохранение AGENTS.md и отказ при изменённом исходнике.
- Проверка пакета после исполнения Python остаётся успешной; CI повторяет
  проверки на Python 3.10/3.13. Локальный Python — 3.11.14.
- Девять независимых исполнений до упаковки: восемь v1, повтор BE-07R на v2.
  Пропуск English-поиска исправлен. Три задачи включали bundled Chromium.

## Blocking Issues

По выполненным проверкам нет. Публикация не расширяет подтверждённый объём.

## Non-Blocking Risks

Experimental: разные модели/многократные повторы, физические телефоны, полный
WCAG, field CWV, внешние лицензии и реальные CMS/Svelte-сборки этим набором
не подтверждены. Текущий catalog — метаданные, не одобренный код.

## Docs / Versioning Notes

Версия дистрибутива 0.4.0; формат реестра решений 1.0, спецификация контрактов 0.2.
При обновлении сравните изменившиеся основные пакеты, сохраните локальные правки
вне обнаруживаемых skills и осознанно замените согласованный набор. Отдельная
установка elements не обновляет другие пакеты автоматически.

## Recommended Next Action

Установить нужный набор в целевой сайт и применять только к разрешённой задаче.
Для выбранного внешнего элемента проверить текущие файлы/права/зависимости
и повторить относящиеся к нему UI-проверки.
