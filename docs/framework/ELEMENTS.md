# Элементы сайтов

Дополнение 0.4.0, 19 октября 2026. Самодостаточный пакет
[ai-design-elements](../../.agents/skills/ai-design-elements/SKILL.md) работает
внутри direction/implementation/review и по самостоятельной задаче по существующему
дизайну. Четыре этапа и 22 основных критерия сохраняются.

| Режим | Результат и границы |
| --- | --- |
| Подбор | Задача, существующие компоненты, совместимые кандидаты и обоснование; исходники и зависимости сохраняются |
| Реализация | Разрешённая адаптация, происхождение, notices, состояния и проверка в интерфейсе |
| Ревью | Отчёт отдельно от продукта; доказательства относятся к конкретной версии |

Начинайте с кода/решений своего сайта. Затем рассматривайте нативный HTML,
средства CMS и внешние источники под реальный стек. React/Tailwind/MCP не
обязательны. Существующий бренд и согласованная локальная правка сохраняются.
Основные этапы работают и без нового пакета, выполняя эти действия напрямую.

## Каталог и CLI

В пакете 43 указателя: базовые элементы, примитивы, композиции, движение,
формы/данные, графика, иконки, типографика и инструменты. Указатель — кандидат,
не одобренный код. Отдельные сведения shadcn/ui и React Bits сверялись по
первоисточникам; остальные источники остаются исследовательскими данными.
Для выбранного элемента заново проверяются файлы, версия, права на нужное
использование, зависимости и notices. Права на конечный сайт не подтверждают
право распространять исходники библиотекой.

В целевом проекте после установки:

```sh
python3 .agents/skills/ai-design-elements/scripts/elements.py search "форма" --stack react
python3 .agents/skills/ai-design-elements/scripts/elements.py search dialog --stack svelte
python3 .agents/skills/ai-design-elements/scripts/elements.py search --id react-bits
python3 .agents/skills/ai-design-elements/scripts/elements.py search "форма" --records design/ELEMENTS.json
```

CLI использует Python 3.10+ без сторонних зависимостей/сети. Это текстовый
поиск с русскими/английскими метками, фильтрами и отдельным списком локальных
записей. `--stack` фильтрует подсказку, не проверяет совместимость.
Метки не являются подтверждённым списком компонентов внешнего источника.
[Все команды и ограничения](../../.agents/skills/ai-design-elements/references/catalog.md).
MCP может использоваться отдельно, если он доступен и входит в задачу;
пакет не настраивает и не запускает его.

## Решение по элементу

Для небольшой задачи достаточно записи в IMPLEMENTATION/REVIEW; полный реестр
не обязателен. Для накопления решений:

```sh
python3 .agents/skills/ai-design-elements/scripts/elements.py new --id contact-form --task "Подготовить обращение" --out design/ELEMENTS.json
python3 .agents/skills/ai-design-elements/scripts/elements.py check design/ELEMENTS.json --project-version site-snapshot-02
```

Каталог `design/` должен существовать. `new` не перезаписывает существующий файл.
`check` ничего не меняет; код 0 — полнота записи, 1 — открытые условия,
2 — ошибка формата/входа. Пустой реестр не означает успешную приёмку.
[Формат записи](../../.agents/skills/ai-design-elements/references/records.md).

`verified-record` означает полноту записанных утверждений текущей версии.
CLI не читает сами доказательства и не подтверждает права, безопасность,
WCAG, видимое качество или решение владельца. Старые проверки не переносятся
на новую сборку или другой проект. Условия приёмки:

| ID | Условие |
| --- | --- |
| EL-01 | Задача/стек определены, существующий компонент рассмотрен, новая платформа не навязана |
| EL-02 | Источник/версия, права, notices и зависимости выбранных внешних файлов известны либо оставлены открытыми |
| EL-03 | Адаптация следует DESIGN, применимые состояния/размеры проверены в интерфейсе |
| EL-04 | Режим записи соблюдён; доказательства актуальны для проекта/версии |
